## Contribuire

I contributi sono benvenuti! Sentiti libero di inviare una Pull Request.

### Sviluppo

**NOTA:** esegui `make help` per maggiori informazioni su tutti i possibili target `make`.

Elenca i target disponibili:

```bash
make help
```

- Esegui i controlli:

```bash
make lint-ctzd
make test-ctzd
```

### Pull Request

- Mantieni le modifiche focalizzate e ben descritte.
- Aggiorna la documentazione in `docs/website/` quando cambi CRD o comportamento.

### Maggiori informazioni

Maggiori informazioni sono disponibili nella [documentazione di Kubebuilder](https://book.kubebuilder.io/introduction.html).
